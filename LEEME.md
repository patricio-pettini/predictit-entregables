# Entregables de PredictIT

Trabajo Final de Ingeniería · Pettini, Patricio Ezequiel · B00072710-T1 ·
**Grupo 2** · Universidad Abierta Interamericana

Una carpeta por entrega, con la fecha que le corresponde al Grupo 2. La cátedra
alterna el orden de los grupos entre entregas, así que la fecha del Grupo 1 no
sirve de referencia y por eso no está acá.

| Carpeta | Qué se entrega | Fecha |
|---|---|---|
| `ENTREGA TECNOLOGIA/PRIMER ENTREGA` | La base del sistema: arquitectura, seguridad, bitácora, trazabilidad, multiidioma y el código fuente | **15/09/2026** |
| `ENTREGA NEGOCIO/PRIMER ENTREGA` | El plan de negocio y el presupuesto financiero | **18/09/2026** |
| `ENTREGA NEGOCIO/SEGUNDA ENTREGA` | El plan corregido con la devolución de la primera | **16/10/2026** |
| `ENTREGA TECNOLOGIA/SEGUNDA ENTREGA` | El sistema avanzado | fecha por confirmar con la cátedra |
| `ENTREGA FINAL` | El paquete completo: documento, manuales, documentación técnica, gestión y defensa | **11/11/2026** |

Todas se arman con un comando y ninguna se edita a mano:

```
python _armar-entregables.py     # la final
python docs/negocio/_entrega-1.py    # las dos primeras
```

Son **salidas**: se borran y se vuelven a armar enteras desde `docs/`. Un
archivo puesto a mano acá desaparece en la próxima corrida, y esa es la
intención — que lo que se entrega sea siempre lo que se trabajó.
